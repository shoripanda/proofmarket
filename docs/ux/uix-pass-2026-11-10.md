# UI/UX pass — 2026-11-10

Base: `main` at a03974c. Branch `feat/uix-overnight`. Scope: fix defects and rough edges found by walking the
public site and the worker app; no product, API or spec changes.

## 1. How the audit was done

- Local server (`pnpm dev:local`, DEV_MODE, PGlite seed) driven with Playwright at 360/390 px (phone) and
  1440 px (desktop), `reducedMotion: "reduce"` so the scroll-reveal animation does not hide content.
- Public pages: `/`, `/en`, `/try`, `/how-it-works`, `/developers`, `/pricing`, `/faq`, `/join`, `/connect`,
  `/demo`, `/data`, `/stats`, `/map`, `/rules`, `/workers`, `/console/login`, unknown URLs, `/r/<missing id>`.
- Worker flow end to end with a fake camera and location: login → onboarding → tour → task list → task →
  claim → capture → answer → verdict → earnings, plus `/jobs` and `/profile`.
- Per page: horizontal overflow (`scrollWidth > clientWidth`, and which element causes it), interactive
  elements smaller than 32 px, images without `alt`, unlabeled links/buttons, console errors.

No image without `alt`, no unlabeled control and no unexpected console error was found.

## 2. Findings

| # | Where | What happens | Severity |
|---|---|---|---|
| F1 | `/data` (phone) | The page scrolls sideways (424 px on a 360 px screen). The grid item holding the `curl` block keeps its min-content width, so the `<pre>` cannot scroll inside itself and pushes the page. | Bug |
| F2 | `/stats` (phone) | The 14-day chart overflows (414 px). Each column's `11/10` label sets a min width; 14 of them do not fit. | Bug |
| F3 | `/onboarding`, `/join`, `/connect` | The consent checkbox shrinks when its label wraps to several lines (flex item without `shrink-0`), so the box the worker must tick is smaller than the others. | Bug |
| F4 | Any unknown URL | Next's default English "404 This page could not be found." with no header, no way back, and in English on the Japanese site. | Bug |
| F5 | `/r/<id>` with no result | A single grey sentence and nothing else; no link back to the site. | Rough edge |
| F6 | Worker screens (claim, verdict, task, earnings, …) | The body is empty until the API answers — on a slow phone line the worker sees a blank screen under the header. | UX |
| F7 | Worker header | Back arrow, sound toggle and "Earnings" link are about 28–32 px tall; below the 44 px touch target the rest of the app uses. The tour's "Skip" is 28 px. | UX / a11y |

| F9 | Verdict screen | Success is a plain text "✓" glyph in the body font; the most rewarding moment in the app looks unfinished. | Polish |
| F10 | `/jobs`, `/profile` while tasks are off | "Tasks are not open yet" is shown in the red error style, and an empty "Open" heading follows it. It is a state, not an error. | Polish |

## 3. Design

Principles: keep the current visual language (teal-700, slate, rounded-2xl cards, the press feedback added in
#65); fix at the shared component where possible so every page benefits; no new dependencies; respect
`prefers-reduced-motion`; every string in Japanese and English via `pick`.

- **F1** — `min-w-0` on both grid children in `/data`, so `<pre class="overflow-x-auto">` scrolls inside its box.
- **F2** — `min-w-0` on the chart columns; on phones show the date label only on every other day (and always
  on the last), all labels from `sm` up. Bars keep their `title` with the full date.
- **F3** — `shrink-0` on the four checkboxes (onboarding, profile, join form, connect flow).
- **F4** — `app/not-found.tsx`: a bilingual page inside the normal site chrome (`SiteShell`), with a short
  explanation and three ways forward (home, how it works, sample results). `/legal/[doc]` and other
  `notFound()` calls get the same page.
- **F5** — add "Back to ProofMarket" and "What is this page?" (how it works) links under the message.
- **F6** — `Loading` component in `components/ui.tsx`: two pulsing card-shaped placeholders with an
  `aria-live` "Loading…" for screen readers (no pulse under reduced motion). Used by every worker page whose
  body is `null` until data arrives and that has no error.
- **F7** — header controls get `min-h-11 min-w-11` with centered content; "Skip" in the tour gets the same.
- **F8** — footer links get vertical padding (`py-1.5`) so each row is ≥ 32 px, the legal row too.
- **F9** — `SuccessMark`: an SVG check in a teal circle that draws itself once (stroke-dashoffset, CSS only,
  static under reduced motion), plus one line telling the worker what happens next (payment is on its way).
- **F10** — `TASKS_NOT_ENABLED` renders as a neutral `Notice` and hides the list section.

## 4. Out of scope (noted for later)

- Amounts show as `0.5 USDC` where the API returns `"0.5"`; formatting money to 2 decimals touches the API
  contract and the agent-facing text, so it needs its own change.
- The 3 answer buttons on capture use grey for "Not open", which can read as disabled. A colour change there
  touches the worker's answer, so leave it for a decision by the owner.
