作成: 2026-10-09。決まりは `README.md` と同じ（リンクは返信に、ハッシュタグ無し、画像を必ず付ける、「初の・唯一の」を書かない）。日本語→英語の順で交互に出す。同じ組は同じ日に。

## 1 組目: 入口（どちらのテスターにも）

**日本語**

> AI エージェントに「いま渋谷のあの店、開いてる？」と聞いたら、人が見に行って、写真つきで答えが返ってくる。
>
> そういう仕組みを作りました。いま、試す人を探しています。
>
> ・スマホで数分の作業を引き受けてくれる人（東京）
> ・自分のエージェントから依頼を出してみたい開発者
>
> 登録なしで体験できるページもあります。返信にリンクを置きます。

**English**

> Ask your AI agent "is that shop in Shibuya open right now?" and a real person goes, looks, and answers with a photo.
>
> We built that. Now we need people to break it.
>
> - Workers in Tokyo: a few minutes on your phone per task
> - Developers: send requests from your own agent (MCP, x402, or REST)
>
> There is a no-signup demo you can run in the browser. Link in the reply.

- **画像**: `/try` の画面（エージェントの吹き出しと worker の写真が並ぶところ）
- **返信（日）**: 体験はこちら https://proofmarket.fun/try ／ 参加の申し込み https://proofmarket.fun/join
- **返信（英）**: Try it: https://proofmarket.fun/en/try · Apply: https://proofmarket.fun/en/join

## 2 組目: worker のテスター

**日本語**

> 店の前を撮る。掲示を書き写す。行列の長さを答える。
>
> 依頼は AI エージェントから届き、受けるかどうかは毎回自分で決められます。暗号資産の知識は要りません。ログインすれば受取口座は自動でできます。
>
> いまは試験運用なので、報酬はテスト用の USDC です。本当のお金は動きません。その代わり、仕組みの壊し方を教えてくれる人を優先して招待します。

**English**

> Photograph a storefront. Transcribe a notice. Count a queue.
>
> Requests come from AI agents. You decide, every time, whether to take one. No crypto knowledge needed; a wallet is created when you log in.
>
> It is a pilot, so rewards are test USDC — no real money yet. In return, the first invites go to people who will tell us what breaks.

- **画像**: worker アプリの依頼一覧（iPhone の画面）
- **返信（日）**: 招待コードの申し込み https://proofmarket.fun/join ／ 仕事の中身 https://proofmarket.fun/workers
- **返信（英）**: Apply for an invite: https://proofmarket.fun/en/join · What the work looks like: https://proofmarket.fun/en/workers

## 3 組目: 開発者のテスター

**日本語**

> エージェントが自分では確かめられないことを、人に頼める API を作っています。
>
> MCP なら claude.ai や ChatGPT のコネクタとして、x402 なら登録なしで USDC を払って、REST なら API キーで。答えには写真の検査・位置・時刻・Solana の記録が付いて返ります。
>
> 自分のエージェントから依頼を出して、おかしいところを教えてくれる開発者を探しています。API キーは申し込みの日に送ります。

**English**

> An API for the things your agent cannot check by itself.
>
> MCP (works as a connector in claude.ai and ChatGPT), x402 (pay in USDC, no signup), or REST with an API key. Every answer comes back with photo checks, location, time, and a Solana record.
>
> Looking for developers who will send requests from their own agents and tell us what is wrong. API keys go out the same day you apply.

- **画像**: 見本エージェントのターミナル録画（402 → 支払い → 201）か、`/developers` の依頼文の JSON
- **返信（日）**: 開発者向け https://proofmarket.fun/developers ／ API キーの申し込み https://proofmarket.fun/join
- **返信（英）**: Developers: https://proofmarket.fun/en/developers · Get a key: https://proofmarket.fun/en/join
